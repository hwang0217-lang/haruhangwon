GED 4과목모의고사 40회와 영한 교재

==============================

119,000원해외 결제 $99
결제 준비 중무료 체험판 받기

체험판: 모의고사 1회 + 교재 첫 단원 · 어떻게 작동하나요?

이렇게 작동해요

설치도, 회원가입도, 인터넷도 필요 없어요. 파일 하나를 브라우저로 열면 그 안에 교재, 모의고사, 채점, 기록이 다 들어 있어요.

  1. 1. 받고 열기

    결제하면 내려받기 링크가 화면과 이메일로 와요. zip 파일의 압축을 풀고 안에 있는 HTML 파일을 더블클릭하면 크롬이나 엣지에서 바로 열려요. 한 번 받은 뒤에는 인터넷이 끊겨도 그대로 쓸 수 있어요.

  2. 2. 첫 화면에서 "지금 할 일" 따라가기

    첫 화면이 지금 해야 할 공부 하나를 골라 줘요. 순서는 진단 → 약점 공부 → 연습 → 실전이에요.

    • 과목마다 1회를 먼저 풀어 지금 실력을 확인해요(진단).
    • 점수가 60%보다 낮은 영역의 교재 단원을 공부해요.
    • 2~8회로 연습하고, 9~10회는 시간 제한을 켜고 실전처럼 풀어요.
    • 과목별로 몇 회까지 풀었는지, 최근 점수가 몇 점인지 한눈에 보여요.

  3. 3. 교재로 공부하기

    단원마다 핵심 용어 → 개념 → 예시 → 자주 하는 실수 → 확인 문제 순서예요. 꼭 외울 문장과 숫자에는 형광펜이 칠해져 있어서, 시간이 없을 때는 형광펜만 훑어도 돼요. 다 읽으면 "다 읽었어요"를 눌러 표시해요.

  4. 4. 모의고사 풀기

    • 실제 시험 시간 타이머: 실제 시험의 문항 수와 시간에 맞춰 문항당 시간이 같아요. 시간이 끝나면 자동으로 제출해요.
    • 나중에 다시 보기: 헷갈리는 문제에 표시해 두고, 문제 목록에서 번호를 눌러 바로 돌아가요.
    • 제출 전 확인: 안 푼 문제가 있으면 몇 문제인지 알려 주고 한 번 더 물어봐요.
    • 수학은 시험장처럼 공식표를 열어 볼 수 있어요. 9~10회는 시작하면 시간 제한이 자동으로 켜져요.

  5. 5. 바로 채점, 약점 분석

    • 실제 GED처럼 100~200점으로 환산하고, 합격선 145점까지 몇 점 남았는지 알려줘요.
    • 영역별 정답률을 낮은 순서로 보여주고, 60% 미만은 빨간색으로 표시해요.
    • 빨간 영역을 누르면 그 내용을 다루는 교재 단원이 바로 열려요.
    • 문제마다 내 답, 정답, 해설을 보여줘요.

  6. 6. 결과 다시 보기

    지난 회차 결과는 언제든 다시 열어 볼 수 있어요. 문제마다 정답과 오답, 해설이 남아 있어요. "결과 복사하기"로 점수 요약을 보호자에게 카톡으로 보낼 수도 있어요.

  7. 7. 내 기록과 설정

    • 푼 기록은 쓰는 기기의 브라우저에 자동으로 저장돼요. 같은 기기, 같은 브라우저로 열면 이어서 할 수 있어요.
    • 인터넷 사용 기록을 지우거나 다른 기기로 옮기면 기록이 사라질 수 있어요.

어디서 열면 되나요?

  • 가장 좋아요: 윈도우나 맥 컴퓨터의 크롬 또는 엣지
  • 됩니다: 안드로이드 휴대폰·태블릿의 크롬 (파일 앱에서 HTML 파일을 눌러 크롬으로 열기)
  • 권장하지 않아요: 아이폰·아이패드는 파일을 여는 방법이 번거롭고 기록이 저장되지 않을 수 있어요.
  • 사기 전에 무료 체험판으로 내 기기에서 잘 열리는지 먼저 확인해 보세요.

학원·인강 대신, 파일 하나로 끝내는 GED

특징

  • 1) 실제 점수 체계로 즉시 채점: 실제 GED처럼 과목당 100~200점, 합격선 145점으로 점수를 보여주고 해설을 바로 확인해요.
  • 2) 약점 분석: 영역별 정답률을 낮은 순으로 보여주고, 누적 기록으로 약한 부분을 짚어줘요.
  • 3) 교재 바로 연결: 빨간색 약점 영역을 누르면 해당 교재 단원이 바로 열려요.
  • 4) 영한 혼합 교재: 시험에 나오는 영어 용어는 그대로, 설명은 쉬운 한국어로. 핵심 용어 → 개념 → 예제 → 자주 하는 실수 → 확인 문제 순서.
  • 5) 실제 시험 시간 타이머: 실제 GED와 같은 문항당 시간(수학 115분/46문항 기준 → 32문항 80분)으로 타이머가 자동으로 돌아가요. 9~10회 실전 회차는 시간 제한이 자동으로 켜지고, 5분 남으면 빨간색으로 알려줘요.
  • 6) 실전 같은 화면: 문제 목록, 나중에 다시 보기, 수학 공식표, 언어 지문·문제 나란히 보기.
  • 7) 대시보드: '지금 할 일'만 따라가면 진단 → 약점 공부 → 연습 → 실전 순서로 자동 안내.
  • 8) 설치·회원가입·인터넷 필요 없음: HTML 파일 하나를 더블클릭하면 브라우저에서 바로 열려요.
  • 9) 결과 복사: 버튼 하나로 점수 요약을 복사해 카톡으로 보호자·선생님께 보낼 수 있어요.
