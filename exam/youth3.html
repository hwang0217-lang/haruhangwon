이렇게 작동해요

설치도, 회원가입도, 인터넷도 필요 없어요. 파일 하나를 브라우저로 열면 그 안에 교재, 모의고사, 채점, 기록이 다 들어 있어요.

  1. 1. 받고 열기

    결제하면 내려받기 링크가 화면과 이메일로 와요. zip 파일의 압축을 풀고 안에 있는 HTML 파일을 더블클릭하면 크롬이나 엣지에서 바로 열려요(기기별 여는 방법). 한 번 받은 뒤에는 인터넷이 끊겨도 그대로 쓸 수 있어요.

  2. 2. 첫 화면에서 "지금 할 일" 따라가기

    첫 화면이 지금 해야 할 공부 하나를 골라 줘요. 순서는 진단 → 약점 공부 → 연습 → 실전이에요.

    • 과목마다 1회를 먼저 풀어 지금 실력을 확인해요(진단).
    • 점수가 60%보다 낮은 영역의 교재 단원을 공부해요.
    • 2~8회로 연습하고, 9~10회는 시간 제한을 켜고 실전처럼 풀어요.
    • 과목별로 몇 회까지 풀었는지, 최근 점수가 몇 점인지 한눈에 보여요.

  3. 3. 교재로 공부하기

    단원마다 핵심 용어 → 개념 → 예시 → 자주 하는 실수 → 확인 문제 순서예요. 꼭 외울 문장과 숫자에는 형광펜이 칠해져 있어서, 시간이 없을 때는 형광펜만 훑어도 돼요. 다 읽으면 "다 읽었어요"를 눌러 표시해요.

  4. 4. 모의고사 풀기

    • 실제 시험 시간 타이머: 실제 시험의 문항 수와 시간에 맞춰 문항당 시간이 같아요. 2분 남으면 빨간색이 되고, 시간이 끝나면 자동으로 제출해요. 설정에서 끌 수도 있어요.
    • 나중에 다시 보기: 헷갈리는 문제에 표시해 두고, 문제 목록에서 번호를 눌러 바로 돌아가요.
    • 제출 전 확인: 안 푼 문제가 있으면 몇 문제인지 알려 주고 한 번 더 물어봐요.
    • 회차마다 쉬움 30%, 보통 50%, 어려움 20%로 섞여 있고, 회차끼리 같은 문제가 나오지 않아요.

  5. 5. 바로 채점, 약점 분석

    • 실제 시험의 만점, 합격선, 과락 기준으로 점수와 합격 여부를 보여줘요.
    • 영역별 정답률을 낮은 순서로 보여주고, 60% 미만은 빨간색으로 표시해요.
    • 빨간 영역을 누르면 그 내용을 다루는 교재 단원이 바로 열려요.
    • 문제마다 내 답, 정답, 해설을 보여줘요. 난이도별 점수도 나와요.

  6. 6. 틀린 문제만 다시 풀기

    오답 노트에 틀린 문제가 모여요. "오답만 다시 풀기"로 풀어서 맞히면 목록에서 빠져요.

  7. 7. 내 기록과 설정

    • 푼 기록은 쓰는 기기의 브라우저에 자동으로 저장돼요. 같은 기기, 같은 브라우저로 열면 이어서 할 수 있어요.
    • 인터넷 사용 기록을 지우거나 다른 기기로 옮기면 기록이 사라질 수 있어요. 처음부터 다시 하려면 "기록 모두 지우기"를 눌러요.
    • 글자 크기를 보통, 크게, 아주 크게 중에서 고를 수 있어요.
    • "결과 복사하기"로 점수 요약을 복사해 가족이나 선생님에게 보낼 수 있어요.
    • 문제 한글 해석: 영어 문제는 한국어 해석을 보이거나 숨길 수 있어요. 익숙해지면 숨기고 실전처럼 풀어요.

받은 파일, 이렇게 열어요

윈도우 컴퓨터 (추천)

  1. 받은 zip 파일을 마우스 오른쪽 버튼으로 누르고 모두 압축 풀기를 눌러요.
  2. 풀린 폴더의 .html 파일을 바탕화면으로 옮겨요.
  3. 더블클릭하면 크롬이나 엣지에서 열려요. 다른 프로그램으로 열리면 오른쪽 버튼 → 연결 프로그램 → Chrome.

맥

  1. zip 파일을 더블클릭해 압축을 풀어요.
  2. .html 파일을 더블클릭하면 사파리나 크롬에서 열려요.

안드로이드폰·태블릿

  1. html 파일을 내려받거나 카톡으로 받아 저장해요.
  2. 내 파일 → 다운로드에서 파일을 눌러요.
  3. 삼성 인터넷 또는 Chrome을 골라요. 카톡 미리보기나 HTML 뷰어에서는 작동하지 않아요.

아이폰·아이패드

  1. 내려받은 파일은 아이폰 파일 앱·카톡 미리보기에서 작동하지 않아요. 컴퓨터나 안드로이드 기기로 열어 주세요.
  2. 무료 체험판은 위의 바로 풀어 보기를 누르면 아이폰 사파리에서도 풀어 볼 수 있어요.

기록 저장

  1. 점수·진도는 그 기기, 그 브라우저에 자동 저장돼요. 로그인은 없어요.
  2. 같은 기기의 같은 브라우저로 열어야 이어져요. 컴퓨터와 폰 기록은 따로예요.
  3. 시크릿 창이나 인터넷 기록·쿠키 삭제를 하면 기록이 지워져요.
  4. 여는 방법이 잘못되면 화면 위에 노란색·빨간색 안내가 번호로 떠요. 그대로 따라 하면 돼요.

사기 전에 무료 체험판을 내려받아, 공부할 기기에서 잘 열리는지 먼저 확인해 보세요.
